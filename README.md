# Vovan Frontend

## Установка и запуск

### 1. Установить Node.js
Скачать: https://nodejs.org/ (на сайте заранее стоит нужный пресет для скачивания, просто установить его)

### 2. Скачать проект
Скачайте из репозитория фронт, для этого либо используйте git, либо другим удобным вам способом.

**Установка Git:** https://git-scm.com/install/

После установки Git, в терминале прописать:
```bash
git clone https://github.com/respir0/Pedyk.git
cd Pedyk

npm install

npm start
