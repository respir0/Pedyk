# Vovan Frontend

1. Установить Node.js - скачать: https://nodejs.org/ (на сайте заранее стоит нужный пресет для скачивания, просто установить его)

## Запуск

2. Скачайте из репозитория фронт, для этого либо используйте git, либо другим удобным вам способом.
Скачать git - https://git-scm.com/install/
После установки, в терминале прописать следующее: 
git clone <https://github.com/respir0/Pedyk.git>
cd Pedyk

4. Установить зависимости. В терминале прописать:
npm install

5. После установки зависимостей в терминале для запуска пишем:
npm start

После всего вышеперечисленного в браузере должнп открыться необходимая страница
